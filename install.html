🎬 Kodi POV IL — מדריך התקנה מלא

כל מה שצריך לדעת מההורדה ועד הצפייה הראשונה

📌 איזו שיטת התקנה מתאימה לי?

בחר את המצב שלך — ועבור ישר לשיטה הרלוונטית:

אין לי Kodi בכלל, יש לי טלפון אנדרואיד / טאבלט / סטרימר Android TV
→ שיטה 1 (Downloader)
אין לי Kodi, יש לי מחשב Windows
→ שיטה 2 (Windows Setup)
אין לי Kodi, יש לי טלוויזיית LG (webOS)
→ שיטה 3 (IPK)
יש לי Kodi מותקן (ריק או עם משהו אחר)
→ שיטה 4 (Wizard) או שיטה 5 (File Manager)
יש לי בילד אחר ורק רוצה תרגום AI
→ שיטה 6 (תוסף בודד)

⚠️ הערה חשובה — 32-bit מול 64-bit

זה לא קשור לעוצמת המכשיר — זה רק עניין של ארכיטקטורת המעבד שהמכשיר תומך בה. כלל פשוט:

  • אנדרואיד 64-bit → טלפונים, טאבלטים, ו-Nvidia Shield Pro 2019. (הסטרימר היחיד שתומך ב-64-bit. הגרסה הלא-Pro של Shield היא 32-bit!)
  • אנדרואיד 32-bit → כל שאר הסטרימרים והטלוויזיות החכמות (Android TV boxes, Onn 4K, Xiaomi Mi Box, Chromecast with Google TV, וכו')
  • Windows / מחשב נייד → השתמש ב-Installer הייעודי (שיטה 2). אין צורך לבחור 32 או 64 ידנית.
ב-Downloader (שיטה 1) — תבחר ה-APK שמתאים למכשיר שלך לפי הסיווג למעלה. אם בטעות תוריד את הלא נכון — ההתקנה פשוט תיכשל ותחזור לבחור אחר.

📱 שיטה 1 — התקנה ל-Android דרך Downloader (טלפון / טאבלט / סטרימר)

הדרך המומלצת לכל מכשיר אנדרואיד — טלפון, טאבלט, או סטרימר Android TV. Downloader מספק עמוד בחירה אחד שמוביל לקובץ המתאים לכל מכשיר.

שלב א' — התקן את אפליקציית Downloader

  • טלפון / טאבלט אנדרואיד: Google Play → חפש "Downloader" של AFTVnews → התקן
  • סטרימר Android TV: בחנות האפליקציות של המכשיר → חפש "Downloader" של AFTVnews → התקן

שלב ב' — הזן את הכתובת הישירה (הדרך הכי אמינה)

הזן ל-Downloader את הכתובת הישירה לקובץ ה-APK המתאים — ההורדה מתחילה מיד בשלב אחד, בלי דף ביניים:

  • פתח את Downloader, ובשדה ה-URL הזן את הכתובת לפי המכשיר:
  • אנדרואיד 64-bit (טלפון / טאבלט / Shield Pro): morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-64bit.apk
  • אנדרואיד 32-bit (Fire TV / שאר הסטרימרים): morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-32bit.apk
  • לחץ GO (כפתור צהוב) → ההורדה מתחילה (~75MB)
נתקע על "Connecting" ולא יורד? זה קורה כשמזינים קוד שמוביל לדף בחירה (HTML) במקום ישירות לקובץ — Downloader לא מוריד דפי אינטרנט. הזן את הכתובת הישירה המלאה למעלה (מצביעה ישירות על ה-APK) וזה יעבוד.
חלופה — דרך קוד ודף בחירה: אפשר גם להזין את הקוד 6699594 שמוביל לעמוד בחירה (32/64-bit, Windows, webOS) וללחוץ על כפתור ההורדה הצהוב הגדול. אם נתקע — חזור לכתובת הישירה למעלה. איזו גרסה? טלפון / טאבלט / Shield Pro → 64-bit; כל סטרימר אחר → 32-bit (הסבר מלא).

שלב ג' — התקן

  • בסיום ההורדה → לחץ Install
  • אם זו הפעם הראשונה — המכשיר יבקש לאפשר ל-Downloader להתקין אפליקציות. אפשר (זה חד פעמי)
  • אם אנטי-וירוס מזהיר — אפשר להמשיך, ה-APK בטוח
  • בסיום ההתקנה → לחץ Done (לא Open עדיין) → חזור ל-Downloader → Delete את הקובץ (כדי לא לבזבז מקום)
  • עכשיו פתח את Kodi POV IL מתפריט האפליקציות

שלב ד' — הפעלה ראשונה

  • פתח את "Kodi POV IL"
  • חכה 30-60 שניות — הוויזרד יותקן אוטומטית ויטעין את הבילד
  • בסיום יופיע מסך הבית עם POV מותקן
אלטרנטיבה למתקדמים: אם אתה לא רוצה Downloader — אפשר להוריד את ה-APK ישירות מ-GitHub Releases דרך דפדפן במכשיר ולפתוח לאחר ההורדה.

💻 שיטה 2 — התקנה ל-Windows

שלב א' — הורד את ה-Setup

  • הורדה ישירה: Kodi-POV-IL-Setup.exe (תמיד הגרסה האחרונה)
  • או דרך עמוד ה-releases: github.com/MoranTheKing/Kodi-POV-IL/releases/latest

שלב ב' — התקן

  • לחץ פעמיים על הקובץ שהורדת
  • אם Windows Defender יזהיר → לחץ "More info" → "Run anyway"
  • עקוב אחרי המתקין: Next → Next → Install → Finish

שלב ג' — פתח

"Kodi POV IL" יופיע בתפריט התחל. בפעם הראשונה הוויזרד יותקן ויחל הבילד אוטומטית.

📺 שיטה 3 — התקנה ל-LG TV (webOS)

דורש את Developer Mode של LG. למתקדמים בלבד.
  • הורד Kodi-POV-IL-webos.ipk (הורדה ישירה — תמיד הגרסה האחרונה)
  • הפעל Developer Mode על הטלוויזיה: webostv.developer.lge.com/develop/getting-started/developer-mode-app
  • השתמש ב-ares-install כדי להתקין את ה-IPK

🧙 שיטה 4 — התקנה דרך Wizard (אם כבר יש Kodi)

מתאים לך אם יש לך Kodi 21+ ריק או עם בילד אחר ואתה רוצה להתקין את POV IL FENtastic.

שלב א' — הוסף Source

  • Kodi → הגדרות (גלגל שיניים) → מנהל קבצים (File Manager)
  • לחץ פעמיים על "הוסף מקור" (Add Source) בחלון השמאלי
  • בכתובת הזן: https://morantheking.github.io/Kodi-POV-IL/wizard/
  • בשם הזן: pov
  • אישור (OK)

שלב ב' — אפשר התקנה ממקורות לא ידועים (חובה ב-Kodi 21!)

בלי השלב הזה ההתקנה תיכשל בלי הסבר ברור. Kodi 21 חוסם התקנה מ-zip כברירת מחדל לאבטחה.

  • Kodi → הגדרות (גלגל שיניים) → מערכת (System)
  • גלול ל-Add-ons (תוספים)
  • "Unknown sources" (מקורות לא ידועים) → הפעל ל-ON
  • תופיע התראה — אישור

שלב ג' — התקן את ה-Wizard

  • חזור ל-Kodi → Add-ons (בתפריט הראשי)
  • לחץ על כפתור הקופסה בפינה השמאלית למעלה
  • Install from zip file
  • בחר pov → plugin.program.kodipovilwizard-latest.zip
  • אם תופיע התראת אזהרה על מקור לא ידוע — אישור
  • חכה להודעה "הותקן בהצלחה"

שלב ד' — אוטומטי

הוויזרד יזהה שאין בילד מותקן ויפעיל את עצמו אוטומטית. אין צורך לעשות כלום ידנית.

  • הוויזרד ישאל אם לשמור הגדרות קיימות (Trakt, Debrid, Favorites וכו') — אשר את כולן אלא אם רוצה התקנה נקייה לחלוטין
  • חכה — הוויזרד יוריד את הבילד (~50MB), ינקה ויתקין הכל
  • בסיום Kodi יבקש סגירה ופתיחה מחדש → אשר
אם משום מה לא התחיל אוטומטית: אפשר להפעיל ידנית דרך Kodi → Programs (בתפריט הראשי) → Kodi POV IL Wizard → Install Build → Kodi POV IL — FENtastic.

📂 שיטה 5 — התקנה דרך File Manager (ידנית מלאה)

עבור מי שרוצה שליטה מלאה ולא רוצה Source.

חובה לפני התחלה ב-Kodi 21: Settings → System → Add-ons → "Unknown sources" → ON (ולאשר את ההתראה). בלי זה התקנת ה-zip תיכשל עם ההודעה "נכשל בהתקנת הרחבה מקובץ".
  • הורד ידנית מ-GitHub: plugin.program.kodipovilwizard-latest.zip (הוויזרד) ואת קובץ הבילד העדכני Kodi-POV-IL-FENtastic-test-*.zip (הגרסה האחרונה) מתיקיית dist
  • העתק את שני הקבצים למכשיר
  • ב-Kodi: Add-ons → קופסה → Install from zip file → בחר את הוויזרד
  • הפעל את הוויזרד דרך Programs ובחר Install Build → Install from local zip (ובחר את הזיפ של הבילד)

🤖 שיטה 6 — רק תוסף ה-AI על בילד קיים

עבור מי שיש לו כבר בילד אחר (Twilight / FEN / Diggz / וכו') ורק רוצה תרגום AI איכותי.

מומלץ: התקנה דרך המאגר (Source) — מקבלת עדכונים אוטומטית. כך Kodi יעדכן את התוסף לבד בכל גרסה חדשה, בלי להוריד zip ידנית כל פעם.

אפשרות א' (מומלצת) — דרך מאגר / כתובת מקור

שלב א' — הוסף Source

  • Kodi → הגדרות (גלגל שיניים) → מנהל קבצים (File Manager)
  • "הוסף מקור" (Add Source)
  • בכתובת הזן: https://morantheking.github.io/Kodi-POV-IL/repo/
  • בשם הזן: povil-ai → אישור

שלב ב' — אפשר "מקורות לא ידועים" (חובה ב-Kodi 21!)

בלי זה ההתקנה תיכשל עם "נכשל בהתקנת הרחבה מקובץ".

  • הגדרות → System → Add-ons → "Unknown sources" → ON → אשר

שלב ג' — התקן את המאגר

  • Add-ons → כפתור הקופסה → Install from zip file
  • בחר povil-ai → repository.kodipovilai-1.0.0.zip
  • חכה ל"הותקן"

שלב ד' — התקן את התוסף מהמאגר

  • Add-ons → Install from repository → POV IL - תרגום AI
  • Subtitle add-ons → Kodi POV IL - AI Subtitles → Install
  • מעכשיו Kodi יעדכן אותו אוטומטית בכל גרסה חדשה.

אפשרות ב' — קובץ zip בודד (בלי עדכון אוטומטי)

שלב א' — הורד את התוסף הבודד

service.subtitles.kodipovilai-latest.zip

קישור יציב — תמיד מצביע על הגרסה העדכנית. (שים לב: בדרך הזו תצטרך להוריד שוב ידנית כדי לעדכן.)

שלב ב' — אפשר "מקורות לא ידועים" (כנ"ל)

  • הגדרות → System → Add-ons → "Unknown sources" → ON → אשר

שלב ג' — התקן

  • Add-ons → קופסה → Install from zip file → נווט לזיפ שהורדת → אשר
  • חכה ל"הותקן"

שלב ד' — הפעל אם דרוש

Add-ons → My add-ons → Subtitles → אם התוסף מופיע כ-Disabled → Enable

אחרי שיש Gemini key (סעיף הבא) — התרגום ירוץ אוטומטית. גם DarkSubs/All_Subs יזהו אותו ויעבירו אליו את כל הבקשות.

🔑 חיבור Gemini AI — חובה לתרגום AI

זה הלב של התוסף. בלי Gemini אין AI.

שלב א' — קבל מפתח חינמי

  • בטלפון (קל יותר עם מקלדת) → כנס ל: aistudio.google.com/apikey
  • התחבר עם חשבון Google רגיל
  • לחץ "Create API key" → "Create API key in new project"
  • העתק את המפתח (משהו כמו AIzaSy...)

שלב ב' — חבר ב-Kodi (הדרך הקלה — QR)

  • במסך הבית של Kodi → "חיבור שירותים להרחבת POV"
  • בחר Gemini AI
  • בחר 📱 התאמה מטלפון / מכשיר אחר (QR + URL)
  • הוצא טלפון → סרוק את ה-QR (או פתח את ה-URL בדפדפן)
  • הדבק את המפתח → שלח
  • ב-Kodi יופיע "החיבור הצליח" → סיימת

שלב ב' חלופי — דרך הגדרות התוסף

אם אין QR נגיש או רוצה לעקוף:

  • Add-ons → My add-ons → Subtitles → Kodi POV IL - AI Subtitles → Configure
  • בחר "📱 התאם מטלפון / מכשיר אחר (QR + URL)" — אותו QR flow
  • או הזן ידנית ב-Gemini API Key → הדבק → OK → לחץ "בדיקת חיבור"
📊 על המכסה החינמית: Gemini Flash Lite מאפשר 500 בקשות ביום בחינם (ללא כרטיס אשראי). בפועל = ~10-30 סרטים ביום, יותר ממה שהמשתמש הממוצע צריך.
בסיום — תרגום AI מופעל אוטומטית. גם דרך DarkSubs (אם תבחר כתוביות באנגלית — AI יתרגם לעברית ברמה מצוינת) וגם דרך התוסף הבודד.

⭐ חיבור TMDB — אופציונלי, מומלץ מאוד

TMDB משמש לרשימות אישיות — Favorites, Watchlist, רשימות מותאמות אישית.

למה דווקא TMDB ולא Trakt לזה?

  • אין הגבלות במנוי חינם (Trakt מגביל ל-100 פריטים ב-Collections)
  • יש להם אפליקציה נוחה לטלפון ואתר נקי לעריכה
  • מסונכרן בין כל המכשירים

איך לחבר

  • מסך הבית של Kodi → "חיבור שירותים להרחבת POV" → TMDB
  • עקוב אחרי ההוראות — תידרש להתחבר עם חשבון Google ולאשר גישה
  • חזור ל-Kodi → סטטוס יעבור ל"מחובר"

אחרי שמחובר

  • ה-tiles "הסדרות שלי (TMDB)" ו"הסרטים שלי (TMDB)" במסך הבית יציגו את ה-Favorites שלך
  • בלחיצה ארוכה על סרט/סדרה תהיה אופציה "ניהול רשימות (TMDB)" להוסיף/להסיר
  • אפשר לראות ולנהל גם מאפליקציית TMDB בטלפון

🎬 חיבור Trakt — אופציונלי, מומלץ למי שצופה בכמה מכשירים

Trakt הוא השירות היחיד שמסנכרן progress של נגינה בין מכשירים. אם התחלת סרט בטלפון ורוצה להמשיך בסטרימר — חייבים Trakt. TMDB לא תומך ב-progress sync.

איך לחבר

  • מסך הבית → "חיבור שירותים להרחבת POV" → Trakt
  • יופיע קוד 5 ספרות + URL
  • במחשב/טלפון → trakt.tv/activate
  • הזן את הקוד → אשר
  • חזור ל-Kodi → סטטוס "מחובר"

חשוב להגדיר נכון

POV → הגדרות → Trakt → Watched Indicators = Trakt (אם משאיר על POV — ה-progress נשמר רק מקומית במכשיר הזה)

אחרי שמחובר ומוגדר

  • "המשך צפייה" / "הפרק הבא" מסונכרן בין כל המכשירים
  • ה-tiles "הסדרות שלי (Trakt)" ו"הסרטים שלי (Trakt)" מציגים את ה-Collection
  • ב-context menu — אופציה "ניהול רשימות (Trakt)"
📝 על מנוי חינם של Trakt: progress sync ב-free tier אינו מוגבל. רק Collections / Lists מוגבלים ל-100 פריטים — אבל בבילד שלנו נטינו ל-TMDB לרשימות, אז free tier של Trakt מספיק לחלוטין למה שאנחנו משתמשים בו.

🔄 עדכונים — איך לוודא שיש לי את הגרסה האחרונה

הבילד מתעדכן אוטומטית דרך Quick Update:

  • בכל פעם שעולה Kodi → אם יש עדכון, יופיע popup
  • ניתן גם להריץ ידנית: tile "עדכון מהיר - Wizard" במסך הבית
  • אחרי quick_update → restart ל-Kodi (סגירה + פתיחה מחדש)
  • כל ה-patchers ירוצו ויחילו את השינויים
אם יש בעיה — לפני שתפנה לעזרה: הרץ quick_update + restart פעם אחת. רוב הבעיות נפתרות.

⚠️ פתרון בעיות נפוצות

Downloader נתקע על "Connecting" ולא מוריד

הבעיה הכי נפוצה ב-Shield/Android TV. זה קורה כשמזינים ל-Downloader קוד שמוביל לדף בחירה (HTML) במקום ישירות לקובץ — Downloader יודע להוריד קבצים, לא לגלוש בדפי אינטרנט, אז הוא נתקע. הפתרון: הזן ב-Downloader את הכתובת הישירה לקובץ ה-APK:

  • 64-bit: morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-64bit.apk
  • 32-bit: morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-32bit.apk

הכתובות האלה מורידות את ה-APK ישירות (~75MB) בשלב אחד. ראה שיטה 1.

"ההתקנה נכשלה" באנדרואיד

ייתכן שיש לך גרסה קודמת מותקנת עם חתימה שונה → הסר את האפליקציה הקיימת → התקן מחדש. בדוק שבחרת את הגרסה הנכונה (32-bit לרוב הסטרימרים, 64-bit לטלפונים / טאבלטים / Shield Pro 2019) — ראה סעיף 32/64-bit.

"נכשל בהתקנת הרחבה מקובץ" בתוך Kodi 21 (התקנת zip)

זה Kodi 21 שחוסם Install from zip file כברירת מחדל לאבטחה. הפתרון:

  • Kodi → הגדרות (גלגל שיניים) → System → Add-ons
  • "Unknown sources" → ON
  • תופיע התראת אבטחה — אישור
  • חזור ל-Add-ons → Install from zip file → נסה שוב

זה לא קשור ל-POV — Kodi 21 דורש את זה לכל זיפ של תוסף שלא מהמאגר הרשמי.

הוויזרד תקוע בהתקנה הראשונית

בדוק שיש אינטרנט יציב (לפחות 5Mbps). אם תקוע יותר מ-2 דקות — סגור את Kodi לחלוטין (לחיצה ארוכה על Home, בחירת Force Stop) ופתח מחדש. בפעם השנייה הוויזרד ימשיך מאיפה שעצר.

"תרגום AI לא עובד"

  1. וודא שיש Gemini key מחובר: Add-ons → My add-ons → Subtitles → AI Subtitles → Configure → Gemini API Key
  2. וודא ש-DarkSubs דלוק: Add-ons → DarkSubs → Configure → "הפעל תרגום מכונה (Gemini AI)" = ON
  3. אם עדיין לא — restart ל-Kodi

Trakt מחובר אבל progress לא מסונכרן

POV → הגדרות → Trakt → Watched Indicators = Trakt (ולא POV)

מסך הבית נראה דחוס

יש לך כלי לסידור tiles בבילד: "סידור מועדפים" במסך הבית. אפשר לסדר, למחוק, ולהוסיף tiles משלך דרך תפריט ההקשר של Kodi.

"התקנתי מחדש ואיבדתי הגדרות"

ב-Wizard בהתקנה יש אפשרויות Keep Trakt Data, Keep Favorites, Keep Gemini וכו'. ברירת המחדל שומרת את כולן. אם איבדת — סימן שביטלת בטעות. בפעם הבאה בדוק שכל ה-Keep מסומנים לפני שמאשר את ההתקנה.

התקנתי רק את התוסף בנפרד וההגדרות לא נשמרות

ידוע — באג של Kodi 21 ב-Android עם הזנה ידנית של שדות string. השתמש בכפתור "התאם מטלפון (QR)" בהגדרות התוסף במקום הזנה ידנית. QR עוקף את הבעיה.
