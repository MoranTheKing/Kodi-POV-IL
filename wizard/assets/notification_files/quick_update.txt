תרגום AI: לחיצה על אנגלית בכל תוסף = תרגום AI אוטומטי
1) השינוי הגדול: עכשיו, כשאתה לוחץ על כתובית באנגלית מכל תוסף (DarkSubs ואחרים), אם הגדרת Gemini API key - התוסף שלי יתרגם אוטומטית. בלי הגדרה - גוגל תרגום ימשיך לעבוד בדיוק כמו עד היום (אפס רגרסיה). 2) Self-healing: כל הפעלה של Kodi מוודאת שהחיבור ל-DarkSubs מקומו, ואם עדכון של DarkSubs מחק אותו - הוא נכנס שוב אוטומטית. 3) כפתורי "נקה Cache" / "נקה Temp" / "Get API key" / "Test connection" עכשיו יופיעו באמת בהגדרות (היה תיקון schema של Kodi 21).
