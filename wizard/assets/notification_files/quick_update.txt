תיקון תרגום AI: API key של OpenSubtitles
ה-API key של OpenSubtitles בתוסף הקודם לא היה תקין (403 Forbidden), ולכן ה-AI subtitles לא מצא כתוביות. עכשיו צריך להגדיר API key חינמי שלך בהגדרות התוסף - תיכנס ל-Settings → Add-ons → Subtitle add-ons → Kodi POV IL - AI Subtitles → Configure → Translation → OpenSubtitles API Key, ותלחץ על "הרשמה חינמית" שמופיע מעליו.
