תרגום AI: הפסקת תרגום מכונה כפול
מעכשיו, ברגע שהגדרת Gemini API key, התוסף משבית אוטומטית את התרגום-מכונה של תוסף הכתוביות All_Subs (Google Translate / Bing / Yandex) - כך שהשורות בעברית שמופיעות בחיפוש הכתוביות יהיו רק שלנו (Gemini, איכות הרבה יותר גבוהה) ולא שורות גוגל-תרגום שהיו מתחרות ולפעמים מנצחות. פעולה חד-פעמית: אם אי-פעם תרצה את התרגום-מכונה של All_Subs בחזרה - פשוט תפעיל אותו ידנית בהגדרות של אותו תוסף, אנחנו לא ניגע בו שוב.
