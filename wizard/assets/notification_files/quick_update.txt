תיקון כותרת UUID בדיאלוג כתוביות — עכשיו רואים שם קובץ אמיתי גם בטורבוקס
המשתמש הראה צילום מסך אחרי quick_update הקודם: האחוזים עלו (33-50% ב-TorBox במקום 0%), אבל למעלה בכותרת הדיאלוג עדיין הופיע ה-UUID `1f1203d5-fc0e-481f-a93a-83584b6cad28` — גיבריש שאי אפשר להשוות אליו ויזואלית את שמות הכתוביות.

**הסיבה שמצאתי:** בdarksubs general.py:517, DarkSubs קוראת native Window property בשם `subs.player_filename`:
```python
video_data['Tagline_From_Fen'] = xbmcgui.Window(10000).getProperty("subs.player_filename")
video_data['Tagline'] = video_data['Tagline_From_Fen'] or video_data['VideoPlayer.Tagline']
```
ובsub_window.py:59 הכותרת בדיאלוג מורכבת מ:
```python
self.video_file_name_label = self.video_data['Tagline'] or self.video_data['file_original_path']
```

הפאצ' הקודם תיקן את `file_original_path` (האחוזים) אבל לא כתב ל-`subs.player_filename` (הכותרת). POV (fork של FEN) פשוט שכח לכתוב לproperty הזה.

**v2 patchers:**

1. **pov_source_name_patcher v2** — מוסיף `Window(10000).setProperty('subs.player_filename', item['name'])` לצד ה-props הקיימים. עכשיו DarkSubs מקבל את שם ה-release האמיתי דרך ה-API שלה עצמה גם לכותרת וגם ל-Tagline branch של חישוב האחוזים (engine.py:197 לוקח max ביניהם — אז המעבר ל-Tagline מקפיץ את האחוזים מ-30-50% ל-70-95%).

2. **darksubs_filename_fallback_patcher v2** — מנקה את `subs.player_filename` כש-URL guard נכשל. מונע ערך ישן ממשחק קודם של POV לדלוף ל-playback חדש מ-addon אחר.

**מיגרציה:** שני הפאצ'ים מזהים את ההזרקה של v0.2.28 בקבצים על הדיסק, מבצעים revert ל-original ואז מחילים את גרסת v2. אידמפוטנטי בכל הפעלה.

**תוצאה צפויה:**
- TorBox: כותרת הדיאלוג מציגה `War.Machine.2026.1080p.NF.WEB-DL.DDP5.1.Atmos.H.264-RYNDR.mkv` במקום UUID
- אחוזים מקפיצים מ-30-50% ל-70-95% (כי Tagline branch של engine.py יקבל עכשיו את שם ה-release המלא)
- אפשר סוף סוף להשוות ויזואלית בקלות בין שם הקובץ למעלה לשמות הכתוביות
