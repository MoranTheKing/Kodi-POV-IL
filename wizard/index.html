Kodi POV IL — קבצים להתקנה

1. ה-Wizard המלא (התקנת בילד POV+FENtastic)

מתקין את כל הבילד: סקין, תוספים, ותוסף ה-AI לתרגום כתוביות בעברית — הכל ביחד.

⬇ plugin.program.kodipovilwizard-0.1.6.zip

ב-Kodi: הגדרות → תוספים → התקן מקובץ zip → בחר את הזיפ.
אחרי ההתקנה ה-Wizard יציע את התקנת הבילד אוטומטית.

2. רק תוסף תרגום AI (לבילד אחר/קודי משלך)

אם יש לך כבר Kodi עם בילד אחר ואתה רוצה רק את תוסף תרגום הכתוביות AI לעברית — תוריד את הזיפ הזה ולא צריך את ה-Wizard למעלה.

⬇ service.subtitles.kodipovilai-0.2.3.zip

ב-Kodi: הגדרות → תוספים → התקן מקובץ zip → בחר את הזיפ.
אחרי ההתקנה: הגדרות התוסף → API → הדבק Gemini API key (חינמי מ- https://aistudio.google.com/apikey).
אופציונלי: התקנת DarkSubs (תוסף כתוביות) — אם הוא מותקן, התרגום AI יופעל אוטומטית בלחיצה על כל כתובית לא-עברית.

התקנה ידנית דרך File manager של Kodi? הוסף את הסורס https://morantheking.github.io/Kodi-POV-IL/wizard/ ב-File manager → Install from zip file → בחר את התוסף.
