[B][COLOR FFFFFFFF]Version 1.0.6[/COLOR][/B]

[B]Focus box[/B]
- The focus box is now a solid, softly lit panel with slightly rounded corners instead of a thin outline, so it stands out clearly from any background. It is used everywhere the skin shows a focus box: lists, menus, settings, dialogs and buttons. Hide focus box in lists and menus still turns it off.
- The List, Big list, Fanart 1 and Fanart 2 views, Settings, the file browser and search now use the same box. They still had the old outline.
- The focus box no longer slides from row to row. It moves straight to the new row in Settings, My add-ons, the file browser, search, the PVR channel and recording lists and guide, the channel list on the player screen and the disc menu. The lists in those windows also scroll straight away instead of gliding.
- The outline around the cast list in the video info screen and around the profiles on the login screen no longer glides either.
- New Plain text in the focus box setting in Menus, under Hide focus box (off by default). With it on, the focused text keeps its normal color and the box alone shows where you are, instead of the text also turning the focus color. Add-on names keep their own colors. It only shows while the focus box is on. The color pickers and the audio and subtitle pickers during playback always show the box, so it applies there whatever Hide focus box says.

[B]Lists[/B]
- The List view (video, music, pictures, programs, playlist, search and My add-ons) no longer animates when it scrolls. The rows change straight away as you move, instead of the text sliding from one line to the next.

[B]Colors[/B]
- In the color pickers, the focused color name keeps its own color instead of turning into the focus color, so you can see the color you are about to pick. The box around it shows where you are.
- The default entry at the top of each color picker (Sand, Mint or Blue) is now shown in its own color too, like the rest of the list.

[B]Views[/B]
- New Show clear logos setting in General (on by default). Movie and TV show lists show the clear logo in place of the name in Fanart 3, Big Icons, Panel, Media info, Media info 2 and Fanart 2, and fall back to the name when there is no logo. Seasons and episodes keep their names.
- TV shows and seasons now get their details in the views that left them out, because Kodi treats a show as a folder:
-- Fanart 3 and Fanart 1 show year, episodes and rating (for example 2009 • 23 episodes • 7.4), and Fanart 1 shows the genre again.
-- Fanart 2 shows the details line, the genre and the star rating.
-- Big Icons shows the rating number after the year and episodes.

[B]Home menu[/B]
- Clearing a shortcut in the menu customizer now closes the gap: the shortcuts below it move up one slot. Moving a shortcut up, down, to the top or to the bottom also closes any gaps first, so a section never has empty slots between shortcuts. Sections that already have gaps close up the next time you clear or move something in them.

[B][COLOR FFFFFFFF]Version 1.0.5[/COLOR][/B]

[B]Add-ons[/B]
- Add-on information now has a Versions button, like Estuary. It lets you pick and install another available version of the add-on, and shows in place of Update when no update is waiting.
- The Update button on that screen was labeled Versions by mistake. It now says Update.
- In My add-ons, moving over to the side panel takes the focus color off the add-on you left, so only one place looks focused at a time. It comes back as soon as you return to the list.

[B]Power menu[/B]
- The power menu is rebuilt. The selection outline is now part of the focused icon, so it no longer slides between options and fast navigation can't leave it behind. The outline follows the focus color (with "Use focus color on selection outline"), and the icons stay white.
- New Power menu items setting in General. Pick what the menu shows: Quit, Shutdown, Suspend and Reboot (on by default, so your menu stays the same until you change it), plus Restart Kodi, Minimise, Hibernate, Shutdown timer, Log off, Master lock, Reload skin and Skin settings.
-- Shutdown timer turns into Cancel shutdown timer while a timer is running, and Master lock switches between entering and leaving master mode.
-- Items your device can't do are hidden instead of greyed out, for example Shutdown on Android. Restart Kodi shows on Windows and desktop Linux, Minimise on those and on Mac, Log off only with profiles or the login screen, and Master lock only when locks are set up.
-- If everything ends up switched off or hidden, Quit still shows, so the menu is never empty.
- The menu stays centered and widens to fit however many items are showing.
- Every item closes the menu before it runs, so Reload skin and Skin settings act right away, and the shutdown timer and master lock prompts no longer open on top of the menu.
- New icons for the new items, in the same style as the original four.

[B]Home screen[/B]
- The add-on shortcut row and the Custom 1, 2 and 3 shortcut rows now draw the selection outline as part of the focused item, like the widgets, so it no longer glides between shortcuts. The Live TV row does the same.
- That outline now follows the focus color too, like the widget outlines.
- Moving quickly along a shortcut row no longer shows the outline on two shortcuts at once. The name under a shortcut now appears straight away instead of fading in, which is what was holding the old outline on screen.
- Custom 1, 2 and 3 now show the focused item's fanart as the background, like Movies and TV shows.
- In Set shortcut, Kodi favourites now has a Favourites entry at the top that makes a shortcut to the Favourites window itself. It works even before you have saved any favourites, so the "no favourites yet" message is gone. Your saved favourites are still listed below it.

[B]Views[/B]
- Fanart 3 for episodes and files (video, games and music windows) now starts at the left edge and shows four full images, instead of three with a gap on the left. Focus scrolls in the second slot, so you can always see the next two items coming up.
- Fanart 3 for episodes shows the rating as a number at the end of the details line (for example 56 Minutes • 7.8) instead of stars.
- Fanart 3 for episodes: the episode title and plot moved up, and the plot now shows five full lines before it auto-scrolls, with no half-cut line at the bottom.
- Big Icons: the plot now shows six full lines, with room for letters like p and g on the last one.
- TV shows and seasons with every episode watched now get the watched check mark, also from add-ons such as Red Light that publish episode counts instead of marking the season played. This applies to every view and to the home TV widget.

[B]Lists and colors[/B]
- The current item in a list is now drawn in the highlight color, and the row you are on stays in the focus color, so the two no longer look the same. This covers the installed version in Versions, the current audio and subtitle track, the current choice in the color pickers, the playing item in a playlist and every other list that marks a current item. When you land on the current item itself, it shows the focus color.

[B]Episodes[/B]
- New Focus first unwatched episode setting in General (off by default). When you open a list of episodes, focus jumps to the first one that is unwatched or in progress. It works for your library and for add-ons, without Python.
-- It jumps once each time you enter a list. Opening info or the context menu and closing it again doesn't move you.
-- After watching an episode you come back to the next one. If you stopped part way, you come back to that one.
-- A fully watched list stays where it is. The first 300 items of a list are checked.
-- Kodi shows the last item you were on for a moment before the jump.

[B]Advanced[/B]
- With Debug on (Skin settings > Advanced), the Videos window also shows the focused item's watched details (play count, progress, episode counts) and what the first unwatched jump did. Handy for telling a skin problem from missing add-on data.

[B][COLOR FFFFFFFF]Version 1.0.0 - First release of Onyx[/COLOR][/B]
Onyx is a fork of Quartz (original design by pecinko, code by nonjon). Everything below is new or changed compared to Quartz.

[B]Identity and compatibility[/B]
- Renamed to Onyx (add-on id skin.onyx). New skin name, "Settings - Onyx" header, README.
- About screen: skin name Onyx, maintained by Valar Morghulis, credits list Quartz first.
- Works on Kodi 21 and Kodi 22.
- Removed the second texture theme (Angular); only the default look remains.
- Dependencies cut down to Kodi's GUI API only. script.favourites, script.image.resource.select and the weather fanart images are no longer required.
- Weather fanart helpers are offered for install only when you use that setting. Turning on Show weather tells you if Kodi has no weather service set.
- Kodi favourites are now read straight from Kodi and turned into shortcuts by the skin's own picker, so the script.favourites helper is gone.
- All helper logic is one small script (onyx_tools.py) that only runs when you change a setting. Nothing runs in the background.

[B]Home menu and shortcuts[/B]
- Menu shortcuts can now point at anything, not just the local library: browse video, music, picture and program add-ons, the video and music library, playlists, Kodi favourites, Kodi Live TV and Radio windows, or type a path.
- 20 custom shortcuts per home section (was 6-7). The same picker is used for the widget shortcut slots in the shelf customizer.
- Move a shortcut up, down, to the top or to the bottom from its picker.
- System menu: new Add-on browser item with an on/off toggle in the customizer.
- The KODI category is now called System by default.
- Wider submenu columns so labels scroll less.
- Labels wait about a second before they start scrolling, in lists and under the home menu.
- The home menu stops at the first and last section instead of looping while a key is held.
- The customizer shortcut list stops at the bottom instead of looping.

[B]Home widgets (Movies and TV)[/B]
- New "Add-on widget" option: show any add-on directory in the widget row instead of the library, with a Widget source picker. Falls back to the library if no source is set.
- Clicking add-on widget items works properly: folders (including Next Page) open, playable items play.
- Add-on TV widgets show posters, like Movies.
- The per-item text under each poster is gone. One centered title shows below the row and follows the selection: Name • Year • Rating (TMDB rating).
- Rounded corners on widget artwork.
- Rounded selection outline that is part of the selected item, so it no longer glides between posters.

[B]Views[/B]
- Rounded artwork in Panel, Icons, Big icons, Fanart 1, 2 and 3, Wide thumbs, Media info 2, the large poster beside List and Big List, and the music, picture and program views.
- Rounded selection outline in the poster-style views, drawn with the selected item (no gliding, no clipping).
- List and menu highlight boxes now snap with the focused text, with no lag, including in Fanart 1 and 2.
- Media info and Media info 2 use the same single-line rows as the basic List view (air time line removed, tighter spacing, more rows).
- Big icons: TMDB rating number added after the age rating.
- List and Big List: the poster on the left is moved up to sit nearer the middle of the screen.
- Removed the square frames behind posters and the square overlay on Fanart 1 and 2 so rounded corners show.
- With the focus box hidden, a focused list row shows in the focus color even when an add-on tints its own labels.

[B]Player[/B]

- New Player button color picker for the focused player buttons.

- Focus color picker with 57 colors plus custom hex.
- Option to use the focus color on the selection outline (on by default for new installs).
- Option to hide the focus box in lists and menus.
