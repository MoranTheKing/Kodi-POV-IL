# Kodi POV IL - Onyx

A premium Hebrew, right-to-left skin for the Kodi POV IL build (Kodi 21).
Picked from the Kodi POV IL Wizard: Switch Skin.

Built on Onyx by adamsbuilds, a fork of Quartz by nonjon and pecinko (GPL-2.0, CC BY-SA 4.0).
Fonts: Heebo (SIL Open Font License 1.1, fonts/heebo_license.txt), Noto Mono (fonts/noto_license.txt).

The home, the views 51 and 55, the player screen and the information screen are generated:
edit tools/skin_onyx in the Kodi POV IL repository and run its build.py, not the XML.
