Kodi POV IL — Windows

Installer ל-Windows 64-ביט. מתקין Kodi הרשמי ומשאיר את ה-wizard מוכן בתיקיית addons של Kodi.

הורד Installer

איך מתקינים

1. הורד את ה-installer והרץ אותו (Windows יצריך אישור).

2. ה-installer יתקין Kodi 21.3 שקט ויעתיק את ה-wizard לתיקיית ההגדרות של Kodi.

3. הפעל את Kodi: %APPDATA%\Kodi\addons\packages\plugin.program.kodipovilwizard.zip מחכה לך.

4. ב-Kodi: Settings → Add-ons → Install from zip file → בחר את ה-zip מהמיקום למעלה.

5. ה-wizard יציע להתקין את הבילד אוטומטית.

לחלופין, הוסף את הסורס https://morantheking.github.io/Kodi-POV-IL/ ב-File manager והתקן מתוך הריפו.
