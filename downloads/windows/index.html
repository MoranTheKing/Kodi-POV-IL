Kodi POV IL — Windows

מתקין 64-ביט נפרד ל-Kodi POV IL. הוא שומר את הפרופיל הקיים בעדכון, מתקן את הרשאות ההפעלה למשתמש רגיל ויוצר קיצורי דרך ממותגים שתמיד פותחים את הפרופיל הנכון.

הורד Installer — גרסה אחרונה

איך מתקינים

1. הורד את המתקין ולחץ עליו פעמיים. אישור UAC בזמן ההתקנה הוא תקין; אין צורך לבחור “הפעל כמנהל” כדי לפתוח את האפליקציה לאחר מכן.

2. המתן להודעת הסיום. אם כבר מותקן Kodi POV IL, המתקין יעדכן את קבצי התוכנה אך ישמור את portable_data, ההגדרות והתוספים הקיימים.

3. פתח רק מהקיצור Kodi POV IL בשולחן העבודה או בתפריט התחל. הקיצור מפעיל תמיד מצב -p עם האייקון של POV IL.

4. בהתקנה חדשה ה-Wizard המובנה ישלים את התקנת FENtastic + POV. בסיום Kodi ייסגר; פתח שוב מאותו קיצור.

בעדכון מעל גרסה קודמת מתעדכנים גם הקיצורים והאייקון. אין להסיר את התוכנה לפני העדכון ואין למחוק ידנית את C:\Program Files\Kodi POV IL\portable_data.
