Kodi POV IL — LG TV (webOS)

קובץ IPK ל-LG smart TV עם webOS 4 ומעלה (למעט דגמי K5LP). מבוסס על Kodi 21.0 הרשמי ל-webOS, כולל מיתוג POV IL ו-Wizard מובנה שמשלים את הבילד בהפעלה הראשונה.

הורד IPK — גרסה אחרונה
⚠️ דורש Developer Mode על הטלוויזיה. את קובץ ה-IPK מורידים למחשב ומתקינים ממנו; אין לנסות לפתוח אותו בדפדפן של הטלוויזיה.

הדרך המומלצת

1. הורד את קובץ ה-IPK למחשב.

2. הפעל Developer Mode בטלוויזיה והשתמש ב-DevMode Manager for webOS כדי לבחור ולהתקין את הקובץ. המדריך המעודכן נמצא ב-Kodi Wiki.

3. אם מותקנת גרסה קודמת של Kodi POV IL, התקן את ה-IPK החדש מעליה. מזהה האפליקציה נשמר ולכן זהו עדכון במקום.

חלופה דרך שורת הפקודה

1. פתח חשבון מפתח חינמי ב־webostv.developer.lge.com.

2. ב־TV: התקן את ה־app "Developer Mode" מה־LG Content Store, פתח, התחבר עם החשבון, והפעל Dev Mode Status: ON. רשום את ה־IP שמוצג.

3. במחשב (Linux / macOS / Windows עם Node.js): התקן את ה־CLI:
npm install -g @webos-tools/cli

4. הגדר את ה־TV ב־CLI:
ares-setup-device
(בחר Add, שם MyTV, ה-IP של הטלוויזיה, פורט 9922 ומשתמש prisoner).

5. פתח בטלוויזיה את Key Server, ואז במחשב הרץ ares-novacom --device MyTV --getkey והזן את ה-passphrase שמופיע בטלוויזיה.

6. התקן:
ares-install --device MyTV Kodi-POV-IL-webos.ipk

7. האפליקציה Kodi POV IL תופיע במגירת האפליקציות. בהפעלה הראשונה ה-Wizard משלים את הבילד; לאחר ש-Kodi נסגר יש לפתוח אותו שוב.

הערות חשובות

• יש להאריך את זמן ה-Developer Mode דרך האפליקציה לפני שהוא פוקע, אחרת אפליקציות sideload עלולות להפסיק להיפתח.

• אין אפשרות להפיץ דרך ה־LG Content Store הרשמי בלי תהליך publishing יקר. הזרימה הזו (sideload דרך dev mode) היא הדרך הסטנדרטית של קהילת ה־homebrew של webOS.

• לפי מדריך Kodi, התמיכה היא ב-webOS 4 ומעלה, למעט טלוויזיות המבוססות K5LP.

• מדריך מפורט יותר ב-Kodi Wiki.
