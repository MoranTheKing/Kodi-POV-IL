Kodi POV IL — LG TV (webOS)

קובץ IPK ל־LG smart TVs עם webOS 5+ ‏(2019 והלאה). מבוסס על Kodi 21.0 הרשמי ל־webOS עם ה־wizard וה־FENtastic build כבר מוטמעים.

הורד IPK — גרסה אחרונה
⚠️ דורש developer mode על ה־TV. LG חוסמת התקנה ישירה ב־TVs רגילים. צריך לפתוח חשבון מפתח אצל LG, להפעיל developer mode על הטלוויזיה, ולהשתמש ב־ares-cli מהמחשב כדי להעלות את ה־IPK. תהליך חד־פעמי של ~15 דקות.

איך מתקינים

1. פתח חשבון מפתח חינמי ב־webostv.developer.lge.com.

2. ב־TV: התקן את ה־app "Developer Mode" מה־LG Content Store, פתח, התחבר עם החשבון, והפעל Dev Mode Status: ON. רשום את ה־IP שמוצג.

3. במחשב (Linux / macOS / Windows עם Node.js): התקן את ה־CLI:
npm install -g @webosose/ares-cli

4. הגדר את ה־TV ב־CLI:
ares-setup-device
(בחר Add, שם MyTV, IP מהשלב הקודם, פורט 9922, password alpine).

5. הורד את ה־IPK מהקישור הצהוב למעלה, ואז:
ares-install -d MyTV Kodi-POV-IL-webos.ipk

6. אחרי ההתקנה האפליקציה "Kodi POV IL" תופיע במגירת האפליקציות של ה־TV.

7. בהפעלה הראשונה Kodi עולה → ה־wizard מתחיל אוטומטית להוריד ולהתקין את הבילד (~דקה־שתיים) → Kodi נסגר ונפתח עם POV+FENtastic.

הערות חשובות

• Developer mode פוקע אחרי 50 שעות עד שתאריך אותו דרך ה־app — לא נורא, רק לחיצה אחת.

• אין אפשרות להפיץ דרך ה־LG Content Store הרשמי בלי תהליך publishing יקר. הזרימה הזו (sideload דרך dev mode) היא הדרך הסטנדרטית של קהילת ה־homebrew של webOS.

• TVs ישנים יותר מ־2019 (webOS 3-4) לא נתמכים על־ידי Kodi 21 בכלל — אין IPK ל־webOS הישן.
