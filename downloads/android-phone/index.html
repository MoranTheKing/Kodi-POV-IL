Kodi POV IL — טלפון / Shield / סטרימר חדש

גרסה 64-ביט (arm64-v8a), למכשירים עם מערכת Android שתומכת באפליקציות 64-ביט. מעבד 64-ביט לבדו אינו מבטיח שהמערכת תומכת בכך; אם ההתקנה אינה תואמת למכשיר, השתמש בגרסת 32-ביט.

הדרך הכי אמינה ב-Shield / Android TV (Downloader)

השתמש בקוד הישיר ל-64-ביט — הוא מוריד את ה-APK מיד, בלי דף בחירה שתוקע את Downloader על "Connecting".

1. ב-Shield: Settings → Apps → Install unknown apps → אפשר ל-Downloader.

2. פתח את Downloader הכתום ובשדה ה-URL הזן את הקוד: 5364281

3. לחץ GO — ההורדה תתחיל מיד (~75MB). בסיום → Install → Done → מחק את הקובץ.

אפשר גם להזין את הכתובת המלאה במקום הקוד: morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-64bit.apk

נתקע על "Connecting" ולא מוריד? סימן שהזנת קוד שמוביל לדף בחירה (HTML) ולא ישירות לקובץ. השתמש בקוד הישיר 5364281 (או בכתובת המלאה למעלה) — שניהם מצביעים ישירות על ה-APK, ו-Downloader יוריד בשלב אחד. הקובץ ~75MB — תן לזה כמה שניות אחרי שמתחיל.

טלפון / טאבלט (דפדפן)

1. Settings → Apps → Special access → Install unknown apps → אישור לדפדפן.

2. לחץ על כפתור ההורדה למעלה → פתח את הקובץ שירד → התקן.

3. עם סיום ההתקנה, פתח את Kodi POV IL. הוויזרד המובנה ישלים אוטומטית את התקנת הבילד ויעלה את מסך הבית של Nox. המתן לסיום ההכנה. אם מופיעה בקשה להפעלה מחדש, סגור ופתח את האפליקציה.

ההתקנה נכשלה עם הודעה על חוסר תאימות? נסה גרסה 32-ביט — גם מכשירים חדשים עשויים להשתמש במערכת Android של 32-ביט.

Kodi POV IL משתמש במזהה נפרד (org.xbmc.povi), ולכן יכול להיות מותקן לצד Kodi הרשמי. משתמשים קיימים מקבלים את תיקוני הבילד בעדכון הרגיל ואינם צריכים את ה-APK החדש. אם בעתיד יידרש עדכון לאפליקציה עצמה, מתקינים מעל הקיים בלי להסיר ובלי למחוק הגדרות.
