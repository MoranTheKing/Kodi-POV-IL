Kodi POV IL — טלפון / Shield / סטרימר חדש

גרסה 64-ביט (arm64-v8a). מתאימה ל-Nvidia Shield, רוב הטלפונים, וסטרימרים חדשים.

הורד APK (64-ביט) — גרסה אחרונה

איך מתקינים

1. בטלפון: Settings → Apps → Special access → Install unknown apps → אישור לדפדפן/Downloader.

2. ב-Shield/Android TV: פתח את Downloader הכתום, הזן את הקוד — (יוצב כאן אחרי שתירשם ל-AFTVnews).

3. או הורד ישירות מהדפדפן מהקישור למעלה.

4. עם סיום ההתקנה, פתח את האפליקציה — ה-wizard וה-FENtastic כבר מותקנים.

סטרימר ישן? נסה גרסה 32-ביט (Fire TV ישן יותר וסטרימרים ארמיים).

האפליקציה מותקנת לצד Kodi הרשמי (package id שונה: org.xbmc.kodipovil). אם יש לך Kodi רגיל מ-Play Store, היא לא תיכתב עליו.
