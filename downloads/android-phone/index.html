הדרך הכי אמינה ב-Shield / Android TV (Downloader)

הטריק: הזן ל-Downloader את הכתובת הישירה לקובץ ה-APK — כך ההורדה מתחילה מיד, בלי דף בחירה שתוקע את Downloader על "Connecting".

1. ב-Shield: Settings → Apps → Install unknown apps → אפשר ל-Downloader.

2. פתח את Downloader הכתום ובשדה ה-URL הזן בדיוק:

morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-64bit.apk

3. לחץ GO — ההורדה תתחיל מיד (~75MB). בסיום → Install → Done → מחק את הקובץ.

נתקע על "Connecting" ולא מוריד? זה קורה כשמזינים קוד שמוביל לדף בחירה (HTML) ולא ישירות לקובץ. הזן את הכתובת המלאה למעלה — היא מצביעה ישירות על ה-APK, ו-Downloader יוריד אותה בשלב אחד. הקובץ ~75MB — תן לזה כמה שניות אחרי שמתחיל.

טלפון / טאבלט (דפדפן)

1. Settings → Apps → Special access → Install unknown apps → אישור לדפדפן.

2. לחץ על כפתור ההורדה למעלה → פתח את הקובץ שירד → התקן.

3. עם סיום ההתקנה, פתח את האפליקציה — ה-wizard וה-FENtastic כבר מותקנים.

סטרימר ישן? נסה גרסה 32-ביט (Fire TV ישן יותר וסטרימרים ארמיים).

שים לב: האפליקציה חולקת את אותו package id של Kodi הרשמי (org.xbmc.kodi). אם מותקן אצלך Kodi רגיל מ-Play Store, הסר אותו לפני ההתקנה כדי למנוע התנגשות.
