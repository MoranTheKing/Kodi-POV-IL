Kodi POV IL — Android TV

גרסה 32-ביט (armeabi-v7a). מתאימה ל-Fire TV וסטרימרים ישנים יותר.

⬇ הורד APK (32-ביט) — גרסה אחרונה

הדרך הכי אמינה (Downloader)

השתמש בקוד הישיר ל-32-ביט — הוא מוריד את ה-APK מיד, בלי דף בחירה שתוקע את Downloader על "Connecting".

1. Settings → My Fire TV → Developer options → Apps from Unknown Sources → On (ואפשר ל-Downloader).

2. פתח את Downloader הכתום ובשדה ה-URL הזן את הקוד: 3158525

3. לחץ GO — ההורדה תתחיל מיד (~75MB). בסיום → Install → Done → מחק את הקובץ.

4. עם סיום ההתקנה, פתח את Kodi POV IL. ה-Wizard המובנה ישלים את הורדת FENtastic + POV, יסגור את Kodi בסיום, ואז יש לפתוח את האפליקציה שוב.

אם Kodi POV IL כבר מותקן, מתקינים את ה-APK החדש מעל הקיים — אין להסיר את האפליקציה ואין למחוק הגדרות. כך מתעדכנים גם האייקון והבאנר במסך הבית; אם ה-launcher עדיין מציג עותק שמור, הפעל את המכשיר מחדש פעם אחת.

אפשר גם להזין את הכתובת המלאה במקום הקוד: morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-32bit.apk

נתקע על "Connecting" ולא מוריד? סימן שהזנת קוד שמוביל לדף בחירה (HTML) ולא ישירות לקובץ. השתמש בקוד הישיר 3158525 (או בכתובת המלאה למעלה) — שניהם מצביעים ישירות על ה-APK, ו-Downloader יוריד בשלב אחד.

לא לאיזה סטרימר? נסה גרסה 64-ביט (Shield, סטרימרים חדשים, טלפונים).
