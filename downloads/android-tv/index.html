Kodi POV IL — Android TV

גרסה 32-ביט (armeabi-v7a). מתאימה ל-Fire TV וסטרימרים ישנים יותר.

⬇ הורד APK (32-ביט) — גרסה אחרונה

הדרך הכי אמינה (Downloader)

הטריק: הזן ל-Downloader את הכתובת הישירה לקובץ ה-APK — כך ההורדה מתחילה מיד, בלי דף בחירה שתוקע את Downloader על "Connecting".

1. Settings → My Fire TV → Developer options → Apps from Unknown Sources → On (ואפשר ל-Downloader).

2. פתח את Downloader הכתום ובשדה ה-URL הזן בדיוק:

morantheking.github.io/Kodi-POV-IL/downloads/Kodi-POV-IL-32bit.apk

3. לחץ GO — ההורדה תתחיל מיד (~75MB). בסיום → Install → Done → מחק את הקובץ.

4. עם סיום ההתקנה, פתח את האפליקציה — ה-wizard וה-FENtastic כבר מותקנים.

נתקע על "Connecting" ולא מוריד? זה קורה כשמזינים קוד שמוביל לדף בחירה (HTML) ולא ישירות לקובץ. הזן את הכתובת המלאה למעלה — היא מצביעה ישירות על ה-APK, ו-Downloader יוריד אותה בשלב אחד.

לא לאיזה סטרימר? נסה גרסה 64-ביט (Shield, סטרימרים חדשים, טלפונים).
